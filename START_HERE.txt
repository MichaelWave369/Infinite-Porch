Choose the native portable ZIP for your OS and CPU listed in DELIVERY_REPORT_0.1.2.md.

package, manifest.json lists exact files and hashes. Packages are unsigned; no

Linux/macOS: run ./start.sh in the extracted bundle. Windows: start.ps1 launches a
foreground node; for the two-PC test use field-kit/windows/Porch-FieldLab.ps1.

Never expose the control API or Ollama's control port through the firewall.

On PC-A / PC-B from the Windows field kit, run setup -Alias PC-A (or PC-B) with
-Session field-001. Follow field-kit/windows/START_HERE.md for explicit fingerprint
pairing and bounded model/message/storage grants. The requester command qualify
-Guided automates the sequence while owner revocation/restart remain on the owner PC.
Use only the exact installed real model tag. Mock provider tests never qualify weights.

separately. Import the delivered qualification-gates.json with qualify import-gates
or the UI file input when it is present. It must match this binary's source commit.
It does not import physical or independent-review PASS claims.
