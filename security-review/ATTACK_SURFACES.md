# Threat model and attack surfaces

Assume an untrusted nearby peer, a trusted member exceeding authority, a malicious provider, a hostile website reaching localhost, stale/replayed signed data, malformed/oversized frames, interrupted processes, changing model inventory, clock anomalies and tampered evidence. Protect private inputs, node keys, control tokens, grants/quotas, storage integrity, identity continuity and the fidelity of qualification claims.

Examine invitation recipient/fingerprint/time/one-use handling; advertisement signer/peer/time/model digest validation; grant exact scope, output/input limits, reservation, revocation during execution and concurrent accounting; scoped-client privacy escalation; replay windows and nonce binding; frame parsing bounds before allocation; response parsing/decompression limits; disconnect/deadline/retry ambiguity; durable intent and no duplicate effects after crash; migration backup and state ownership; encrypted chunks, partial transfers, CID/owner binding and tombstones; browser Host/Origin/SSE controls; Windows ACL inheritance, reparse points, install path and PID reuse; operator-controlled firewall scope; field export session isolation, malicious signed role claims, contradictory receipts and false physical promotion.

Expected refusal cases: wrong invitation recipient/fingerprint; reused/expired invitation; untrusted origin; missing/scoped/expired/revoked control authority; grant wrong model/peer/action, quota exhaustion, excess output or duration; revoked peer/grant; unavailable model; LOCAL_ONLY remote pin; overlong prompt/frame/blob; malformed signed record; duplicate job with changed intent; corrupted ciphertext; nonexistent/unauthorized resource; conflicting evidence identity/session/Porch/receipt; unsupported engine; state already in use; future schema; missing state identity; backward clock anomaly. Some input-route refusals have no executor receipt because no private input is transmitted.

DoS, compromise of a privileged OS account, malicious consented models and physical-router facts remain material residual risks. No general remote shell, public DHT, relay, federation, GPU pool, market or arbitrary compute executor has been added.
